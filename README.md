# Мастерская внимания

Офлайн-приложение для детей 6–7 лет с СДВГ: короткие игровые занятия на внимание,
торможение импульсов, слуховую последовательность и саморегуляцию. Наставник — енот Тихон.

**Автор:** Горшков Сергей Владимирович · <https://nookbat.ru>

> Программа — вспомогательный инструмент для занятий вместе со взрослым. Она не ставит
> диагноз и не заменяет специалиста.

## Возможности

- Три мастерские, 10 упражнений:
  - **Внимание:** «Найди красные кружочки», «Что изменилось?», «Слушай и делай», «Стоп-игра»;
  - **Усидчивость:** «Лабиринт», «Пазл», «Собери портфель»;
  - **Спокойствие:** «Дыхание Тихона», «Медленная радуга», «Разминка».
- Короткие сессии (по умолчанию 7 минут), обязательный перерыв, дневной лимит.
- Голосовые подсказки Тихона с субтитрами (RU/EN/ZH), мягкие звуки, громкость не выше 70 %.
- Звёзды и сад/аквариум без рейтингов и сравнений; хвалим за старание.
- Взрослый режим под PIN: настройки, статистика по неделям, PDF/JSON-отчёт, сброс данных.
- Мышь, сенсорный экран, клавиатура, геймпад (Steam Deck: A — выбрать, B — назад, крестовина — перемещение).
- Полностью офлайн: без сети, аккаунтов и телеметрии. Данные хранятся в
  `~/.local/share/masterskaya-vnimaniya` (SQLite).

## Установка

Готовые сборки лежат на странице [Releases](https://github.com/Serge-Nook/masterskaya-vnimaniya/releases).

- **SteamOS 3.x / любой Linux:** `Masterskaya-vnimaniya-<версия>-x86_64.AppImage`. Сделайте файл
  исполняемым (`chmod +x`) и запустите. В Steam его можно добавить как стороннюю игру.
- **Debian 11+ / Ubuntu 22.04+:** `sudo apt install ./masterskaya-vnimaniya_<версия>_amd64.deb`.
- Для ARM64 (aarch64) есть такие же файлы с суффиксами `aarch64`/`arm64`.

## Разработка

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
python -m mv                      # запуск (--windowed — в окне)
QT_QPA_PLATFORM=offscreen python -m pytest -q
QT_QPA_PLATFORM=offscreen python tools/screenshots.py /tmp/shots [ru|en|zh]
```

Ресурсы генерируются офлайн и уже лежат в репозитории:

| Скрипт | Что делает |
|---|---|
| `tools/i18n.py update` / `release` / `check` | обновляет `mv/i18n/*.ts`, собирает `.qm`, проверяет полноту перевода |
| `tools/gen_voice.py` | озвучка фраз Тихона через Piper → `mv/data/voice/<язык>/*.ogg` |
| `tools/gen_sfx.py` | звуки и фоновая музыка → `mv/data/sfx` |
| `tools/subset_cjk.py` | подмножество шрифта Noto Sans SC для китайского |
| `tools/gen_icon.py` | значок приложения |

Сборка пакетов (Docker, база Debian 11 / glibc 2.31):

```bash
packaging/build.sh          # → dist/*.AppImage, dist/*.deb
```

CI (`.github/workflows/build.yml`) запускает тесты и собирает пакеты для x86_64 и aarch64;
по тегу `vX.Y.Z` создаётся релиз с файлами и `SHA256SUMS.txt`.
